# JavaScript Learning Resources 🚀

Welcome to the JavaScript Learning Repository! This repository contains comprehensive JavaScript code examples from basic to advanced levels to help you master JavaScript.

## 📚 Repository Structure

### 🟢 Basics
- Variables and Data Types
- Operators
- Control Flow (if/else, switch)
- Loops
- Functions

### 🟡 Intermediate
- Arrays and Array Methods
- Objects
- ES6 Features (let/const, arrow functions, destructuring, spread/rest)
- Promises and Async/Await
- Classes

### 🔴 Advanced
- Closures
- Prototypes and Inheritance
- Event Loop and Async Programming
- Design Patterns
- Modules

## 🎯 How to Use

1. Clone this repository
2. Navigate to the topic you want to learn
3. Read the code examples and comments
4. Run the examples in your browser console or Node.js
5. Modify and experiment with the code

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/RanokFerdous/javascript_learn.git

# Navigate to any folder and open the files
cd javascript_learn/basics
```

## 💡 Tips for Learning

- Start with the basics folder if you're new to JavaScript
- Read the comments in each file carefully
- Try to modify the code and see what happens
- Practice by writing your own variations
- Move to intermediate and advanced topics as you progress
